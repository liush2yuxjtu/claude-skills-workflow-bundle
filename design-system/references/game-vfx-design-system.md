# Game VFX Design System Reference

## Purpose
Extend a product design system workflow into game assets, skills, effects and runtime validation.

## Core Model

Intent
↓
Player Experience
↓
Screens + Flows
↓
Combat States
↓
Skill Components
↓
VFX Tokens
↓
Assets
↓
Engine Runtime
↓
Snapshot Validation

## VFX Component Contract

Every effect must define:

- identity
- gameplay purpose
- visual language
- trigger
- lifecycle
- states
- parameters
- asset dependencies
- engine implementation
- validation evidence

## Skill Effect States

- idle
- charging
- casting
- impact
- afterimage
- cooldown
- upgrade variant

## Evidence

Never accept only concept art. Require:

- reference image
- implementation snapshot
- runtime capture
- parameter source
- asset provenance
